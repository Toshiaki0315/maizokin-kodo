# 埋蔵金坑道（Buried Treasure Tunnel）

迷路の坑道で金塊をすべて集め、中央に現れる階段から次の坑道へ進むアクションゲームです。追ってくるエイリアンは、穴を掘って落とし、埋めて倒します。

## 動作環境

- macOS 26 Tahoe 以上
- Apple Silicon（M1 以降）の Mac。Intel Mac には対応していません

## インストール

1. [Releases](https://github.com/toshiaki0315/maizokin-kodo/releases) から最新の dmg をダウンロードします
2. dmg を開き、アプリを「アプリケーション」フォルダへドラッグします
3. このアプリは署名されていないため、初回起動時に macOS にブロックされます。一度起動を試みたあと、「システム設定」>「プライバシーとセキュリティ」を開き、「このまま開く」を選んでください

## 遊び方

| キー | 操作 |
| --- | --- |
| ↑ ↓ ← → | 移動・向きを変える |
| Z | 前のマスに穴を掘る（3回で最も深くなる） |
| X | 前のマスの穴を埋める |
| Enter | 開始・次の坑道へ・リトライ |
| P | 一時停止・再開 |
| F | ブラウン管風の表示を切り替える |
| M | 音（BGM と効果音）のオン・オフ |
| ESC | ゲームを終了する（確認あり） |

- 金塊をすべて集めると、中央に階段が現れます
- エイリアンは最も深い穴に落ちると、しばらく動けなくなります。その間に穴を埋めると倒せます
- エイリアンに触れるとミスです。残機がなくなるとゲームオーバーです
